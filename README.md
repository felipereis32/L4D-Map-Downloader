# L4D Map Downloader

Um programa em Python para buscar, baixar e instalar campanhas personalizadas para **Left 4 Dead 1** usando o site GameMaps.

## Funcionalidades

- Busca campanhas disponíveis no GameMaps.
- Baixa e instala campanhas automaticamente.
- Detecta a instalação do Left 4 Dead 1 pela Steam.
- Permite informar manualmente a pasta do jogo caso não seja encontrada automaticamente.
- Suporte aos idiomas Português (Brasil) e Inglês.
- Extrai arquivos compactados utilizando o WinRAR.

## Requisitos

- Windows.
- Left 4 Dead 1 instalado.
- WinRAR instalado.
- Python instalado para executar o código-fonte.

## Como executar o código-fonte

1. Clone este repositório ou baixe os arquivos.
2. Instale as dependências:

   ```bash
   pip install -r requirements.txt
   ```

3. Execute o programa:

   ```bash
   python main.py
   ```
